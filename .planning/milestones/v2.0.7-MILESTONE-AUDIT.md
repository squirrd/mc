## Tech Debt

### CASE_NUMBER implicit env inheritance in podman exec

**Phase:** Cross-phase (33 → 34/35)
**Severity:** Low (non-blocking, works correctly today)

**Problem:** `build_exec_command()` in `attach.py` does not pass `--env CASE_NUMBER` explicitly to the `podman exec` command. `CASE_NUMBER` is available because it was set in the container's environment at creation time (`containers.create()` in manager.py), and Podman exec inherits the container environment by default.

**Impact:** None currently. If Podman's exec env-inheritance behavior were disabled or changed, `mc agent init-case` and `mc agent backplane-login` would see an empty `CASE_NUMBER` and exit early (shell still opens due to `|| true`).

**Fix:** Add `--env CASE_NUMBER` explicitly in `build_exec_command()` alongside the other exec flags.
