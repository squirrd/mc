  <action>
    In build_exec_command(), change the returned command string.

    Current return:
    ```python
    return (
        f"podman exec -it "
        f"--env 'BASH_ENV={bashrc_path}' "
        f"--env 'PS1=[MC-{case_number}] \\w\\$ ' "
        f"{proxy_env}"

    ```

    New return:
    ```python
    return (
        f"podman exec -it "
        f"--env 'BASH_ENV={bashrc_path}' "
        f"--env 'PS1=[MC-{case_number}] \\w\\$ ' "
        f"{proxy_env}"
        f"{container_id} /bin/bash -c 'mc agent init-case || true; exec bash'; exit"
    )
    ```

    Key points:
    - `mc agent init-case || true` — failure is non-fatal; shell opens regardless
    - `exec bash` — replaces the bash -c subshell with the interactive bash, so the user gets a proper interactive shell (correct PID, job control, BASH_ENV is sourced because exec bash reads it)
    - `; exit` at the end remains — auto-closes the terminal window when the user exits bash
    - Do NOT change any other part of attach.py or attach_terminal()

    Update the docstring of build_exec_command() to mention the init-case step:
    Add to the Note section: "Prepends 'mc agent init-case || true' to refresh case data files before interactive shell."
