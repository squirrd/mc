<objective>
Fix the BPL-04 bug: `_get_state_db()` in `backplane_login.py` calls `StateDatabase()` with no path argument, causing it to resolve to the platformdirs default (`~/.local/share/mc/containers.db` on Linux) rather than the host-mounted state file at `~/mc/state/containers.db`. Because these are different paths inside the container, the StateDatabase fallback in the cluster_id priority chain always reads an empty database, and user-entered cluster IDs are written to the wrong location and lost.

Purpose: Restore BPL-04 ("stored cluster_id reused on subsequent mc case N") — without this fix, users are re-prompted for cluster ID every session when sfdc-case.json has no openshiftClusterID.
Output: Fixed `_get_state_db()` function and a unit test confirming the correct path is used.
</objective>
