Implement these module-level helper functions:

`_get_pid_path() -> Path`:
  Returns `Path.home() / "mc" / "state" / "ocm-monitor.pid"`.
  Calls `state_dir.mkdir(parents=True, exist_ok=True)` before returning.

`_is_pid_alive(pid: int) -> bool`:
  Uses `os.kill(pid, 0)`. Returns True on success, True on PermissionError
  (alive but not ours), False on ProcessLookupError (dead).

`_read_pid_file(path: Path) -> Optional[int]`:
  Reads integer from path. Returns None on ValueError or OSError.

`_write_pid_file(path: Path) -> None`:
  Writes `str(os.getpid())` to path.

`_check_and_acquire_lock(pid_path: Path) -> bool`:
  1. existing_pid = _read_pid_file(pid_path)
  2. If existing_pid is not None and _is_pid_alive(existing_pid): return False
  3. If existing_pid is not None and not alive: pid_path.unlink(missing_ok=True)
  4. _write_pid_file(pid_path); return True

`_decode_jwt_exp(token: str) -> Optional[int]`:
  Decodes the middle segment of a JWT (base64url) and extracts the `exp` claim.
  Steps: split on ".", verify 3 parts, add padding (4 - len % 4, skip if result is 4),
  base64.urlsafe_b64decode, json.loads, return int(payload["exp"]) or None.
  Wrap entire body in `try/except Exception: return None`.

`_read_refresh_token(ocm_path: Path) -> Optional[str]`:
  json.loads(ocm_path.read_text()), returns data.get("refresh_token").
  Wrap in `try/except Exception: return None`.

`_minutes_until_expiry(exp: int) -> int`:
  Returns `int((exp - time.time()) / 60)`. Can be negative when already expired.

Implement class `OCMMonitor`:

```python
class OCMMonitor:
    def __init__(self) -> None:
        self._stop_event = threading.Event()
        self._worker_thread: Optional[threading.Thread] = None
```

`start_background_monitor(self) -> None`:
  This method runs synchronously (foreground). It must:
  1. ocm_path = get_ocm_config_path()
  2. If not ocm_path.exists():
       _CONSOLE.print(f"[cyan]ℹ OCM config not found at {ocm_path} — run 'ocm login' to set up[/cyan]")
       return  # No thread needed
  3. token = _read_refresh_token(ocm_path)
     If token is None: logger.debug("OCM refresh_token not found in %s", ocm_path); return
  4. exp = _decode_jwt_exp(token)
     If exp is None: logger.debug("OCM JWT decode failed for token in %s", ocm_path); return
  5. minutes_left = _minutes_until_expiry(exp)
  6. If minutes_left <= _EXPIRY_WARNING_MINUTES:
       _CONSOLE.print(f"[yellow]⚠ OCM token expires in {minutes_left} min — re-logging in...[/yellow]")
       # Fall through to start daemon thread (thread will run ocm login immediately)
     Else:
       # Token fresh — check PID lock before starting polling thread
       pass  # Fall through to PID lock + thread start
  7. Guard: if self._worker_thread and self._worker_thread.is_alive(): return
  8. pid_path = _get_pid_path()
     If not _check_and_acquire_lock(pid_path): return  # Another process is monitoring
  9. self._stop_event.clear()
  10. self._worker_thread = threading.Thread(
          target=self._monitor_worker,
          args=(minutes_left,),
          daemon=True,
          name="ocm-monitor"
      )
  11. self._worker_thread.start()
  12. atexit.register(self._cleanup)
  13. atexit.register(lambda: pid_path.unlink(missing_ok=True))

`_cleanup(self) -> None`:
  If not self._worker_thread or not self._worker_thread.is_alive(): return
  self._stop_event.set()
  self._worker_thread.join(timeout=2.0)

`_monitor_worker(self, initial_minutes_left: int) -> None`:
  Wraps all logic in `try/except Exception as e: logger.error("OCM monitor error: %s", e)`.
  Body:
  1. If initial_minutes_left <= _EXPIRY_WARNING_MINUTES:
       self._run_ocm_login()  # Token was already expiring; run login immediately
  2. Poll loop:
     while not self._stop_event.wait(timeout=_POLL_INTERVAL_SECONDS):
       ocm_path = get_ocm_config_path()
       token = _read_refresh_token(ocm_path)
       if token is None: continue
       exp = _decode_jwt_exp(token)
       if exp is None: continue
       minutes_left = _minutes_until_expiry(exp)
       if minutes_left <= _EXPIRY_WARNING_MINUTES:
         _CONSOLE.print(f"[yellow]⚠ OCM token expires in {minutes_left} min — re-logging in...[/yellow]")
         self._run_ocm_login()

`_run_ocm_login(self) -> None`:
  try:
    result = subprocess.run(
        ["ocm", "login", "--use-auth-code", "--url=prd"],
        check=False  # never raise; we handle returncode manually
    )
    if result.returncode != 0:
        _CONSOLE.print("[yellow]⚠ OCM re-login failed — please run 'ocm login' manually[/yellow]")
  except FileNotFoundError:
    _CONSOLE.print("[yellow]⚠ 'ocm' not found in PATH — please run 'ocm login' manually[/yellow]")
  except Exception as e:
    logger.error("OCM login subprocess failed: %s", e)

Note: subprocess.run without stdout=/stderr= args inherits the terminal — correct for
streaming interactive `ocm login` output. Do NOT suppress the output.

Helper: create a valid JWT with custom payload for tests:
```python
def _make_jwt(payload: dict) -> str:
    """Create a JWT-shaped string with base64url-encoded payload."""
    import base64, json
    payload_bytes = json.dumps(payload).encode()
    # base64url encode without padding
    b64 = base64.urlsafe_b64encode(payload_bytes).rstrip(b"=").decode()
    return f"header.{b64}.signature"
```
