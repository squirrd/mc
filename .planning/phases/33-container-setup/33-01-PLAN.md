<objective>
Add a `claude-downloader` Containerfile stage that installs the Claude Code CLI via npm, and wire it into the final stage so `claude` is available inside the container.

Claude Code is a Node.js CLI distributed via npm (`@anthropic-ai/claude-code`). It requires a Node.js runtime to execute. The stage installs the CLI globally; the final stage copies the result and installs the Node.js runtime.
</objective>

<task type="auto">
  <name>Task 2: Add claude-downloader stage</name>
  <files>container/Containerfile</files>
  <action>
Insert a new stage after the existing `backplane-downloader` stage (Stage 2) and before the `oc-downloader` stage (Stage 3). Name it `claude-downloader`.

The stage should:
1. Use `registry.access.redhat.com/ubi10/ubi:10.1` as the base (full UBI, not minimal — needed for nodejs from DNF)
2. Declare `ARG CLAUDE_VERSION=2.1.80`
3. Install nodejs and npm: `dnf install -y nodejs npm && dnf clean all && rm -rf /var/cache/dnf`
4. Run `npm install -g @anthropic-ai/claude-code@${CLAUDE_VERSION}`
5. Clean npm cache: `npm cache clean --force`

The global npm install puts the claude binary at `/usr/local/bin/claude` and the package at `/usr/local/lib/node_modules/@anthropic-ai/claude-code/`.

Stage header comment should follow the existing format:
```

# =============================================================================
```
